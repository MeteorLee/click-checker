# 데이터 정규화

## 목적

- raw path와 raw event type이 분석 화면에서 어떻게 공통 키로 정리되는지 설명한다.

---

## 1. route key

예:

- `/products/10`
- `/products/24`
- `/products/89/reviews`

이 값들을 그대로 집계하면 경로가 너무 흩어진다.  
그래서 route template을 사용해 공통 key로 묶는다.

예:

- `/products/{id}` -> `product_detail`
- `/products/{id}/reviews` -> `product_reviews`
- `/orders/{id}` -> `order_detail`

---

## 2. 이벤트 공통 키

raw event type도 그대로 두면 분석 화면에서 보기 어렵다.

예:

- `page_view`
- `product_view`
- `signup_submit`
- `register_submit`

이를 공통 key로 정리할 수 있다.

예:

- `page_view` -> `PAGE_VIEW`
- `product_view` -> `PAGE_VIEW`
- `signup_submit` -> `SIGN_UP`
- `register_submit` -> `SIGN_UP`

---

## 3. 정리되지 않은 값

### `UNMATCHED_ROUTE`
- 어떤 route template에도 맞지 않는 path

### `UNMAPPED_EVENT_TYPE`
- 어떤 event mapping에도 맞지 않는 event type

즉 이 값들이 보이면 규칙을 더 추가해야 한다는 뜻이다.

---

## 4. 어디서 관리하나

관리자 콘솔:

- route 규칙
  - `/dashboard/[organizationId]/route-templates`
- event type 규칙
  - `/dashboard/[organizationId]/event-type-mappings`

---

## 5. 왜 필요한가

- 분석 화면에서 값이 너무 흩어지지 않는다.
- 비슷한 행동을 한 키로 묶을 수 있다.
- overview, routes, event types, funnels를 더 읽기 쉽게 만들 수 있다.
