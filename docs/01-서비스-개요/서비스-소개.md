# Click-Checker 서비스 개요

## 1. 문제 정의
웹 서비스 운영자는 자신의 콘텐츠가 얼마나 조회되는지,
어떤 경로가 많이 클릭되는지 쉽게 분석하기 어렵다.

## 2. 해결 방법
이벤트 수집 API를 제공하여
조직 단위로 데이터를 저장하고
일/기간/경로 기준으로 집계 결과를 제공한다.
여기에 관리자 콘솔과 제품 API 가이드를 같이 제공해
로그인한 사용자가 조직을 만들고, API key를 발급받고,
샘플 이벤트를 전송하고, 집계 결과를 확인하는 흐름까지 닫는다.

## 3. 핵심 기능
- 이벤트 수집 API
- 개요/활동/사용자/리텐션/퍼널 집계 조회
- 경로 및 이벤트 타입 정규화
- 관리자 콘솔
- 제품 API 가이드
- 멀티테넌트 기반 데이터 격리

## 4. 현재 사용자 흐름
- 사용자 계정 회원가입/로그인
- 조직 생성 또는 데모 조직 참가
- 조직 API key 확인/재발급
- 이벤트 전송
- 개요/상세 분석 확인
- 제품 API 가이드에서 상세 계약 확인

## 5. 현재 운영 형태
- 외부 진입점은 `https://clickchecker.dev` 하나를 사용한다.
- 브라우저 페이지는 frontend가 응답한다.
- `/api/**`, `/actuator/health` 등은 backend가 응답한다.
- 관리자 콘솔 JWT 인증과 제품 API `X-API-Key` 인증은 서로 분리한다.
