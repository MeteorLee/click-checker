# 관리자 콘솔 도메인 경계

## 목적
- 관리자 콘솔에서 다루는 주체와 제품 API에서 다루는 주체를 구분한다.
- `account`, `organization`, `membership`, `api key`의 경계를 짧게 고정한다.

## 1. 두 종류의 인증 주체

### 관리자 계정
- 로그인 대상은 `Account`다.
- 인증 수단은 `JWT access token + refresh token`이다.
- 보호 경로는 `/api/v1/admin/**`다.

### 제품 API 자격증명
- 이벤트 수집/조회 대상은 `Organization`이다.
- 인증 수단은 `X-API-Key`다.
- 보호 경로는 `/api/events/**`, `/api/v1/events/**`다.

## 2. 관리자 콘솔에서 관리하는 핵심 리소스
- Organization
- OrganizationMember
- Organization API key
- RouteTemplate
- EventTypeMapping

## 3. 멤버십 경계
- `Account`는 여러 organization에 속할 수 있다.
- organization 내부 권한은 `OrganizationMember.role`로 결정한다.
- 현재 역할은 `OWNER`, `ADMIN`, `VIEWER`다.

## 4. 데모 조직 기준
- 운영/로컬 공통 데모 조직은 `organization.id = 99999`를 기준으로 본다.
- `POST /api/v1/admin/organizations/demo/join`은 현재 로그인한 account를 이 조직에 연결한다.
- 데모 데이터 재생성은 조직 자체를 새로 늘리는 방식이 아니라 `99999` 조직을 재사용하는 방식을 기준으로 한다.

## 5. 프런트 화면 기준
- `/organizations`
  - 사용자가 속한 organization 목록 진입점
- `/dashboard/[organizationId]/**`
  - 특정 organization 관리/분석 화면
- `/guide`, `/quick-start`, `/api-key-guide`, `/send-events`, `/data-mapping`, `/analytics-api`
  - 제품 API 사용을 안내하는 가이드 영역
